박스출하 모바일 배포용

- ZIP을 풀고 안의 파일 전체를 정적 웹호스팅에 업로드하세요.
- 배포 주소는 반드시 https:// 로 시작해야 합니다.
- iPhone은 Safari, Android는 Chrome에서 여는 것을 권장합니다.
- iPhone: 공유 → 홈 화면에 추가
- Android: 메뉴 → 홈 화면에 추가/앱 설치
- 엑셀 내보내기는 모바일에서 가능하면 OS 공유창을 열어 파일 앱/Excel로 저장합니다.

ChatGPT의 sandbox 링크나 휴대폰 파일 앱에서 HTML 자체를 여는 방식은 배포가 아니며, 모바일에서 JavaScript/다운로드가 제한될 수 있습니다.
